# petckins

Skins for GUPet: [projects.guteam.net/gupet](https://projects.guteam.net/gupet). Documentation: [doc.guteam.net/gupet](https://doc.guteam.net/gupet).

30 unique animal skins in the `.gupet` format. Every skin is a ZIP archive with `manifest.json` and 18x13 PNG frames. Each release contains one ready-to-install skin.

## Install

Download a `.gupet` file from the release, open GUPet, go to **User skins**, choose **Import .gupet**, and select the file.
